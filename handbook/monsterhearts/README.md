# Monsterhearts 2

Le thème de base propose un gothique sobre, fondé sur un dessin original de cœur et d’épines. `drowned-lake` est une variante strictement visuelle inspirée de la direction générale fanzine, photocopie et cartes des années 1990 de [Monsterhearts: Welcome to Drowned Lake](https://store.steampowered.com/app/3827470/Monsterhearts_Welcome_to_Drowned_Lake/). Elle charge un collage abstrait original, `assets/variants/drowned-lake/zine-lake.svg`, sans reprendre les images promotionnelles, le logo, les personnages, le HTML ou les données du jeu de Ludic Lemur Entertainment.

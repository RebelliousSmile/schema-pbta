# Polices

Le thème embarque trois familles libres, pour évoquer l'esthétique cyberpunk du jeu imprimé sans prétendre être ses polices officielles :

- **Michroma** (400) pour les titres larges ;
- **Jura** (variable, 300 à 700) pour les intertitres et les libellés ;
- **Exo 2** (variable, 100 à 900, droite et italique) pour le corps du texte.

Les fichiers viennent des paquets Fontsource (`@fontsource/michroma`, `@fontsource-variable/jura`, `@fontsource-variable/exo-2`), sous-ensemble latin, au format WOFF2. La licence de chaque famille accompagne ses fichiers :

- [`OFL-Michroma.txt`](./OFL-Michroma.txt)
- [`OFL-Jura.txt`](./OFL-Jura.txt)
- [`OFL-Exo2.txt`](./OFL-Exo2.txt)

Les trois familles sont distribuées sous SIL Open Font License 1.1.

# Polices

Le thème embarque quatre familles libres, pour évoquer la maquette imprimée de Masks sans prétendre être ses polices officielles :

- **Staatliches** (400) pour les grands titres condensés ;
- **Josefin Sans** (variable, 100 à 700) pour les intertitres et les libellés ;
- **Crimson Pro** (variable, 200 à 900, droite et italique) pour le corps du texte ;
- **Comic Neue** (400 et 700) pour les textes à lire à voix haute et les boîtes de moves.

Les fichiers viennent du dépôt `google/fonts` (`ofl/staatliches`, `ofl/josefinsans`, `ofl/crimsonpro`, `ofl/comicneue`) et sont seulement convertis en WOFF2, sans sous-ensemblage ni instance statique : les tables `name` de chaque police restent intactes, Josefin Sans garde donc son nom de famille d’origine. La licence de chaque famille accompagne ses fichiers :

- [`OFL-Staatliches.txt`](./OFL-Staatliches.txt)
- [`OFL-JosefinSans.txt`](./OFL-JosefinSans.txt)
- [`OFL-CrimsonPro.txt`](./OFL-CrimsonPro.txt)
- [`OFL-ComicNeue.txt`](./OFL-ComicNeue.txt)

Les quatre familles sont distribuées sous SIL Open Font License 1.1.

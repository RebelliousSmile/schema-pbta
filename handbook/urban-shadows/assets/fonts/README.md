# Polices

Le thème embarque deux alternatives libres aux familles utilisées dans la
maquette imprimée d’Urban Shadows :

- **League Gothic** pour les grands titres condensés ;
- **Source Serif 4** pour le corps, les sous-titres et les textes mécaniques.

Les fichiers WOFF2 proviennent des paquets Fontsource 5.3.0 et les deux familles
sont distribuées sous SIL Open Font License 1.1. Le texte de la licence est
conservé dans [`OFL-1.1.txt`](./OFL-1.1.txt). Elles ne sont pas présentées comme
les polices officielles du jeu.
